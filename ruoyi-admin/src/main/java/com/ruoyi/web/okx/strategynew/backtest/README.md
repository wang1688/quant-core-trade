# 回测系统使用说明

## 概述

回测系统用于测试策略在历史数据上的表现，计算关键指标包括：
- 成交笔数
- 总收益率(%)
- 胜率(%)
- 最大回撤(%)
- 盈亏比

## 快速开始

### 1. 准备数据

#### 方式一：使用真实历史数据

将CSV格式的K线数据放在 `data/` 目录下，文件命名格式：`{品种}_{时间框架}.csv`

例如：
- `data/BTC_15m.csv`
- `data/ETH_15m.csv`

CSV文件格式（第一行为表头）：
```csv
timestamp,open,high,low,close,volume
2024-01-01 00:00:00,42000.5,42100.0,41900.0,42050.0,1500.5
2024-01-01 00:15:00,42050.0,42200.0,42000.0,42150.0,1600.2
...
```

#### 方式二：使用模拟数据

如果没有真实数据，系统会自动生成模拟数据用于测试。

### 2. 运行回测

```java
// 直接运行主程序
BacktestMain.main(new String[]{});
```

或者自定义回测：

```java
// 初始化回测引擎
String symbol = "BTC";
double initialCapital = 10000.0;
BacktestEngine engine = new BacktestEngine(symbol, initialCapital);

// 加载数据
List<KLine> klines4H = ...;
List<KLine> klines1H = ...;
List<KLine> klines15M = ...;
List<KLine> klines5M = ...;
List<KLine> klines1M = ...;

// 运行回测
BacktestResult result = engine.runBacktest(klines4H, klines1H, klines15M, klines5M, klines1M);

// 打印报告
result.printReport();
```

## 关键指标说明

### 1. 成交笔数
- 回测期间完成的交易总数
- 包括所有策略的交易

### 2. 总收益率(%)
- 计算公式：(最终资金 - 初始资金) / 初始资金 × 100%
- 反映整体盈利能力

### 3. 胜率(%)
- 计算公式：盈利笔数 / 总笔数 × 100%
- 反映交易成功率

### 4. 最大回撤(%)
- 从资金峰值到最低点的最大跌幅
- 反映风险控制能力
- 越小越好

### 5. 盈亏比
- 计算公式：平均盈利 / 平均亏损
- 反映单笔交易质量
- 大于1表示盈利交易平均收益高于亏损交易

## 详细分析

回测完成后会输出详细分析，包括：

### 策略分布
显示每个策略的交易笔数和盈亏情况

### 方向分布
显示做多和做空的交易笔数和盈亏情况

### 持仓时间分析
- 平均持仓时间
- 最短持仓时间
- 最长持仓时间

### 最佳/最差交易
- 单笔最大盈利交易
- 单笔最大亏损交易

## 自定义回测参数

### 修改初始资金

```java
double initialCapital = 50000.0; // 修改为5万美金
BacktestEngine engine = new BacktestEngine(symbol, initialCapital);
```

### 修改回测品种

```java
String symbol = "ETH"; // 修改为ETH
BacktestEngine engine = new BacktestEngine(symbol, initialCapital);
```

### 修改回测周期

通过调整加载的K线数据数量来控制回测周期：

```java
// 回测1年数据（15分钟K线）
int count = 96 * 365; // 96根15M K线 = 1天

// 回测2年数据
int count = 96 * 365 * 2;
```

## 数据聚合

系统支持从较小级别K线聚合到较大级别：

```java
// 从15M聚合到1H
List<KLine> klines1H = DataLoader.aggregateKlines(klines15M, "15m", "1H");

// 从15M聚合到4H
List<KLine> klines4H = DataLoader.aggregateKlines(klines15M, "15m", "4H");
```

## 注意事项

1. **数据质量**：回测结果的准确性依赖于历史数据的质量
2. **滑点和手续费**：当前版本未考虑滑点和手续费，实际收益会略低
3. **过拟合风险**：避免根据回测结果过度优化参数
4. **市场环境变化**：历史表现不代表未来收益
5. **资金管理**：确保初始资金足够支持策略运行

## 性能优化

对于大量数据的回测：

1. 增加JVM内存：`-Xmx4g`
2. 使用并行处理（未来版本）
3. 数据预加载和缓存

## 常见问题

### Q: 回测速度慢怎么办？
A: 减少数据量或优化代码逻辑

### Q: 如何对比不同策略？
A: 分别运行回测并对比结果

### Q: 回测结果与实盘差异大？
A: 考虑滑点、手续费、流动性等实盘因素
