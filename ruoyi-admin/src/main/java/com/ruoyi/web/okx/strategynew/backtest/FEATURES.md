## 性能指标说明

### 夏普比率（Sharpe Ratio）
- 衡量风险调整后的收益
- 值越高越好，>1为良好，>2为优秀

### 索提诺比率（Sortino Ratio）
- 只考虑下行风险的收益比
- 比夏普比率更关注亏损风险

### 卡玛比率（Calmar Ratio）
- 年化收益率 / 最大回撤率
- 值越高越好，>3为优秀

### 盈利因子（Profit Factor）
- 总盈利 / 总亏损
- >1为盈利，>2为优秀

### 恢复因子（Recovery Factor）
- 净利润 / 最大回撤
- 衡量从回撤中恢复的能力
